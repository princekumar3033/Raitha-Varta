# Raitha-Varta | Product Requirements Document

**Internship Project | Confidential**

## PRODUCT REQUIREMENTS DOCUMENT  
### Raitha-Varta  
**Flash-Card Crop Advisory App for Farmers**

- Platform: Android  
- Tech Stack: Android (Java/Kotlin), Room DB, ViewPager2, Glide, GenAI API  
- Target Users: Farmers in Karnataka (Rural, Semi-literate)  
- Language Support: English & Kannada  
- Prepared By: Internship Team  
- Date: 26 April 2026  
- Version: 1.0  
- Status: Draft  
- Domain: Agriculture  

---

## 1. Executive Summary
Raitha-Varta is an Android app that converts complex agricultural advisories into simple swipeable flash-cards for farmers.

---

## 2. Problem Statement
- Advisories are long and complex  
- Farmers need simple, visual content  
- No offline-first advisory tool exists  

---

## 3. Goals
- Daily actionable tips  
- Offline usage  
- Kannada support  
- GenAI-powered insights  

---

## 4. Features
- Flash-card tips  
- Crop filters  
- Offline mode  
- AI expert advice  
- Bookmark & share  

---

## 5. Tech Stack
- Kotlin / Java  
- Room DB  
- ViewPager2  
- Glide  
- GenAI APIs  

---

## 6. User Flow
1. Launch app  
2. View tip  
3. Swipe  
4. Filter  
5. Ask AI  

---

## 7. Non-Functional Requirements
- Fast (<2s load)  
- Offline-first  
- Accessible  
- Lightweight  

---

## 8. Risks
- API limits  
- Device performance  
- Image size  

---

## 9. Glossary
- KVK: Agricultural center  
- Flash-card: Tip screen  
- GenAI: AI-generated content
